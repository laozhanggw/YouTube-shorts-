# 视频流程套件 · 一条短视频从对标到能生成

把一条 YouTube Shorts 那种 60–95 秒的改造／建造片，从「看到一条对标」做到「能导入 AI 视频平台生成」的整套流程。

**这一版是 2026-10-27 定稿版**（生产单元全部对齐阿初口径）。旧口径（一盒 4–10 秒、2–4 刀）已作废，看到就是过期的。

---

|---|---|

## 包里有什么

```
指令\            五份可以直接复制的指令（改最上面一行就能发出去）
skills\          六个 skill，指令里会点名叫它们
模板\            新项目要用的空目录骨架
tools\           配置路径脚本、流程导图生成器
对标库\          拆好的对标放这里
_项目\           每条片子一个文件夹
流程导图.html     可点开的流程图，指令全文内嵌，可直接复制
02_操作流程_图解.html   给人看的操作说明（带流程图，大白话）
01_给AI的接手指南.md    给 AI 看的接手文档
00_先读我.md            最短的一份说明
```

**所有路径都是占位符 `{{ROOT}}`**，指向本套件根目录。跑一次 `tools\设置本机路径.bat` 就会填成本机真实路径。

## 三条铁律（背下来就够用）

| 数 | 是什么 |
|---|---|
| **13–15 秒** | 一次生成装满一组 |
| **6–7 刀** | 一组里装几个镜头 |
| **约 2 秒** | 每个镜头多长 |

为什么是这个数：一个镜头给 2 秒，只够干一件事，干完就得切走，**没有时间站着、走过去、擦汗**。
一个镜头给 5 秒，活 1 秒干完，剩下 4 秒模型只能站着——这就是「铺好了站起来傻站一会儿」的来源。

> 刀数不是规定的，是除出来的：**生成秒数 ÷ 2**。

## 七段流程

```
① 拆解 → ② 复刻 → ③ 开头 ┐
                 ④ 小分镜 ┘→ ⑤ 生产单元 → ⑥ 生成 → ⑦ 复盘
```

③④ 可以同时开两个对话框（T 秒末态已在设定书里写死）。其余严格排队。

- ①②③ 用 Claude
- ④⑤ 用 Codex
- ⑥⑦ 人工

## 这一版相对上一版改了什么

- 生产单元：一盒 **4–10 秒／2–4 刀** → **13–15 秒装满／6–7 刀**
- 撤销「一盒一个工序」「最多两件事」「每刀不少于 2 秒」「12–15 秒必废」
- 剪裁比全库统一为 **0.867**（生成 15 秒 → 成片 13 秒），此前 0.83／0.85／0.87 并存
- 小分镜每刀写两个秒数：成片秒、**素材秒**
- 五段交接补齐：`01_微调大纲.md` 改为 ④⑤ 必读；`改动影响清单.md`、人读版改为不必读

细节见 `流程导图.html` 里「★ 定稿方法论」「★ 踩过的坑」两节。

## 已知边界

- 视频和图片**不在本套件内自动生成**，要去平台上点。本套件只产出文字和检查。
- 每段产出的质量，靠各自那一道机器闸门（`09 工具\检查_*.py`）把关，退出码 0 才算这一段做完。
- 检查脚本不在这个包里（在作者的 `09 工具\` 目录）。需要的话单独要。
